# Lyrics

An experimental C++ compiler front end for the Lyrics scripting language.

## Build and run

1. Open `Lyrics.sln` in Visual Studio with the `v140` C++ toolset and Windows 8.1 SDK installed.
2. Select `Debug | x86` and build the solution.
3. Run from the repository root:

```powershell
.\Debug\Lyrics.exe -s .\Lyrics\script.lyc
```
